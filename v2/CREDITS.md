# V2 engine credits

The test version in this folder plays games with **EmulatorJS** (https://emulatorjs.org, GPL-3.0; licence in `LICENSE-EmulatorJS.txt`), which runs the **mGBA** libretro core (MPL-2.0) through RetroArch compiled to WebAssembly. The engine files are in `ejs/` unchanged. Because EmulatorJS is GPL-3.0, this folder's app code is offered under the same licence.
